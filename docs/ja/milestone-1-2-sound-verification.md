## 検証内容

### PSG検証 (ayumi / emu2149)

- C メジャースケール (C4〜C5) を3チャンネル同時発音（メロディ + ハーモニー + 5度）
- 各音 0.4 秒、合計 3.2 秒
- 44100Hz / 16bit / stereo (ayumi)、44100Hz / 16bit / mono (emu2149)
- WAV ファイルへの書き出しに要した CPU 時間を計測

### FM検証 (ymfm / YM2203 OPN)

- YM2203 (OPN) でアルゴリズム4（2オペ直列）のピアノ風音色を設定
- C メジャースケール (C4〜C5)、Key ON/OFF 付き、合計 4.4 秒
- `chip.sample_rate()` API で取得した内部レート（FIDELITY_MIN: 166400 Hz）で WAV 出力
- WAV ファイルへの書き出しに要した CPU 時間を計測

**注意：** 初回の OPN 検証では内部サンプルレートを誤算（`OPN_CLOCK / 144`）しており
こもった低周波ノイズしか発生しなかった。`chip.sample_rate()` API を正しく使用して
修正済み。詳細は「バグ修正記録」節を参照。

### FM検証 (ymfm / YM2151 OPM)

- YM2151 (OPM)：X1 + FM音源ボード (CZ-8BS1 等)、X1turboZ（標準搭載）、X68000 対象
- ALG=5（ブラス風4オペ音色）を設定
- C メジャースケール (C4〜C5)、Key ON/OFF 付き、合計 4.4 秒
- OPM クロック 4.0 MHz、内部レート 62500 Hz で WAV 出力
- KC レジスタの正規ノートエンコーディング（C=14、C#=0 等のスキップパターン）を実装

## バグ修正記録

### OPN 内部サンプルレート誤算バグ

**症状：** 生成した WAV がこもった低周波ノイズしか出ない

**原因：**
```cpp
// 誤: OPN_CLOCK / 144 = 27733 Hz を内部レートと誤算
const double ymfm_rate = (double)OPN_CLOCK / 144.0;
```

ymfm の `ym2203::sample_rate()` は `OPN_FIDELITY_MIN` 設定時に
`input_clock / 24 = 166400 Hz` を返す。
誤算値 27733 Hz は正しい内部レートの約 1/6 であったため、
音程が大幅に低くなりノイズ状になっていた。

**修正：**
```cpp
// 正: chip.sample_rate() API を使用して正しい内部レートを取得
opn.chip.set_fidelity(ymfm::OPN_FIDELITY_MIN);
uint32_t SAMPLE_RATE = opn.chip.sample_rate(OPN_CLOCK); // = 166400 Hz
```

## 採用決定

### PSG音源エミュレータ：ayumi / emu2149 両採用

| ライブラリ | 用途 | 採用理由 |
|---|---|---|
| **ayumi** | ステレオパン対応が必要な演者チャンネル | チャンネル毎のステレオパン・DC フィルター API が仕様要件に直接合致 |
| **emu2149** | パン不要・高速処理優先の用途 | シンプルで軽量、高速バッチ処理・プレビュー生成向き |

どちらを使うかはプラグイン実装の判断とし、ホスト側は区別しない（完全抽象化）。
両ライブラリとも MIT ライセンスで問題なし。
実機との比較検証は開発環境に実機がないため実施しない。

### その他確定ライブラリ

| 役割 | 採用ライブラリ | 理由 |
|---|---|---|
| FM音源エミュレータ | **ymfm** | Milestone 1-1 の決定を追認。OPN/OPM 両対応確認済み。 |
| オーディオ出力 | **miniaudio** | ヘッダオンリー・依存なし確認済み。出力レイヤーは Milestone 2-1 で正式組み込み。 |
