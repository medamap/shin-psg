## 検証概要

シン・PSGの音源エミュレーション層に採用を検討している以下のライブラリについて、
Linux (Ubuntu 22.04 / g++ 11.4) 環境でのビルド・動作・CPU負荷を検証した。

| 対象 | ライブラリ | バージョン |
|---|---|---|
| PSG音源 (候補A) | ayumi | latest (git) |
| PSG音源 (候補B) | emu2149 | latest (git) |
| FM音源 | ymfm | latest (git) |
| オーディオ出力 | miniaudio | latest (header only) |

検証コード・WAVファイルは `research/milestone-1-2-sound-verification/` に格納。

---

## 検証内容

### PSG検証 (ayumi / emu2149)

- C メジャースケール (C4〜C5) を3チャンネル同時発音（メロディ + ハーモニー + 5度）
- 各音 0.4 秒、合計 3.2 秒
- 44100Hz / 16bit / stereo (ayumi)、44100Hz / 16bit / mono (emu2149)
- WAV ファイルへの書き出しに要した CPU 時間を計測

### FM検証 (ymfm / YM2203 OPN)

- YM2203 (OPN) でアルゴリズム4（2オペ直列）のピアノ風音色を設定
- C メジャースケール (C4〜C5)、Key ON/OFF 付き、合計 4.0 秒
- 44100Hz / 16bit / stereo
- WAV ファイルへの書き出しに要した CPU 時間を計測

## 音質評価

実際に生成した WAV ファイル（`research/milestone-1-2-sound-verification/` 以下）を
聴取して主観評価を実施すること。本レポートでは客観評価のみ記録する。

### ayumi vs emu2149 比較ポイント（聴取確認項目）

| 確認項目 | ayumi | emu2149 |
|---|---|---|
| ピッチ精度 | ステレオ対応・FIR フィルタ付き | モノラル、シンプルな補間 |
| ノイズ特性 | DC フィルタ内蔵 | シンプルな実装 |
| API の使いやすさ | C API（ステレオ出力対応） | C API（int16 直接出力） |
| CPU 負荷比 | 0.0138 | 0.0066（約2倍速い） |

**技術的な推奨：** emu2149 の方が CPU 負荷が低く、API もシンプル。
ただし ayumi はステレオパン・DC フィルタが内蔵されており音質面での優位性がある。
**最終採用はリリース品質での聴取評価で決定する（Milestone 1-2 持ち越し課題）。**

## CMake 統合

`research/milestone-1-2-sound-verification/CMakeLists.txt` に CMake 定義を記述済み。
cmake が利用可能な環境では以下でビルド可能：

```bash
cd research/milestone-1-2-sound-verification
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

本 VM 環境では cmake 未インストールのため g++ 直接コンパイルで検証を実施。
本番の `src/` 統合時は CMake 経由でビルドすること。

## 採用決定

### 確定

| 役割 | 採用ライブラリ | 理由 |
|---|---|---|
| FM音源エミュレータ | **ymfm** | Milestone 1-1 の決定を追認。ビルド・動作・CPU負荷すべて問題なし。 |
| オーディオ出力 | **miniaudio** | ヘッダオンリー・依存なし確認済み。出力レイヤーは Milestone 2-1 で正式組み込み。 |

### 継続検討（Milestone 2-2 で最終決定）

| 役割 | 候補A | 候補B | 判断基準 |
|---|---|---|---|
| PSG音源エミュレータ | **ayumi** | **emu2149** | 実機聴取評価・API設計への適合性 |

聴取評価の観点：
1. AY-3-8910 の音色再現精度（特に MSX / X1 実機との比較）
2. ステレオパン表現（シン・PSGでは演者のパン設定が必要なため ayumi 優位の可能性あり）
3. 音量エンベロープの自然さ
