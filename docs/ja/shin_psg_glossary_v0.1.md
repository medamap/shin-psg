| 日本語 | English | 定義 |
|---|---|---|
| 感度 | Sensitivity | 感情変化へどれだけ速く・強く反応するか。 |
| リミッター | Limiter | 感情パラメータの上限・下限の振れ幅。これを超過すると発狂状態へ移行する。 |
| 感情減衰速度 | Decay Rate | 受け取った感情が収束するまでの速さ。 |

### 5-3. 技術パラメータ

| 日本語 | English | 定義 |
|---|---|---|
| 熟練度 | Skill | 演奏精度全般。低いほど感情の影響が演奏に直接・素直に表れる。高いほど感情が高ぶっても減衰速度が速く演奏精度を維持しやすい。 |

### 5-4. 感情エンベロープパラメータ（9感情 × ADSR）

演者一人あたり9感情×4パラメータ＝36個のエンベロープパラメータが存在する。

| 日本語 | English | 定義 |
|---|---|---|
| アタック | Attack | フィールトラックの値が上昇した際、演者内部の感情値が追従するまでの時間。短いほど即反応する短気な性格。 |
| ディケイ | Decay | 感情値がピークに達した後、サスティンレベルまで落ち着くまでの時間。 |
| サスティン | Sustain | 感情トリガーが持続している間の安定レベル（0.0〜1.0）。 |
| リリース | Release | フィールトラックの感情値が下降した後、演者内部の感情値がゼロに戻るまでの時間。 |

|---|---|---|

## 7. 演奏癖パラメータ

演者が持つ奏法上の癖。MMLで明示しない場合は自動的に演奏に付加される。
MMLで明示した場合はMML指定が優先（上書き）される。

### 7-1. ビブラート癖

| 日本語 | English | 定義 |
|---|---|---|
| ビブラート好き度 | Vibrato Affinity | どれだけビブラートをかけたがるか。0でほぼかけない、1.0で積極的にかける。 |
| 開始タイミング | Vibrato Delay | ノートオン後、ビブラートが始まるまでの時間。 |
| 深さ揺れ | Vibrato Depth Fluctuation | ビブラートの深さが感情に連動して揺れる度合い。 |
| 速度変化感度 | Vibrato Rate Sensitivity | 感情の変化に対してビブラート速度がどれだけ変化するか。 |

### 7-2. トレモロ癖

| 日本語 | English | 定義 |
|---|---|---|
| トレモロ好き度 | Tremolo Affinity | どれだけトレモロをかけたがるか。 |
| 感情連動強度 | Tremolo Emotion Sensitivity | 感情変化に対してトレモロがどれだけ増減するか。 |
| 閾値 | Tremolo Threshold | このstrength値を超えた時にトレモロが発生し始める。 |

### 7-3. ポルタメント癖

| 日本語 | English | 定義 |
|---|---|---|
| ポルタメント好き度 | Portamento Affinity | どれだけポルタメントをかけたがるか。 |
| カーブ形状 | Portamento Curve | 音程移動の基本カーブ形状。イーズイン・イーズアウト・S字・直線など。 |
| アンダーシュート量 | Undershoot Amount | 音程上昇前に一瞬目標音程より下に外れる量。0でなし。弦楽器・声楽奏者が無意識に行う癖の再現。 |
| アンダーシュートカーブ | Undershoot Curve | 下がってから上昇へ転じるカーブの形状。 |
| オーバーシュート量 | Overshoot Amount | 目標音程到達後に一瞬行きすぎる量。0でなし。 |
| オーバーシュートカーブ | Overshoot Curve | 行きすぎてから戻るカーブの形状。 |

## 8. 感情エンジン処理ステージ

フィールトラックの感情データが演奏表現へ変換されるまでの処理フロー。

| ステージ | 名称 | English | 概要 |
|---|---|---|---|
| Stage 1 | フィールトラック入力 | Feel Track Input | 9感情の独立カーブとして入力される。この段階では演奏への影響は発生しない。 |
| Stage 2 | 感情エンベロープ処理 | Emotion Envelope Processing | 各感情の値を演者の感情エンベロープ（ADSR）で時間的に整形する。 |
| Stage 3 | 感情アルゴリズム処理 | Emotion Algorithm Processing | 感情間の変調関係（感情アルゴリズム）に従って感情を合成する。 |
| Stage 4 | Valence-Arousalベクトル変換 | Valence-Arousal Vector Conversion | 処理済み感情データをθとstrengthの2次元ベクトルに変換する。 |
| Stage 5 | 解釈フィルタ | Interpretation Filter | 指揮者・リーダー・演者の解釈フィルタを通じてベクトルをさらに変質させる。 |
| Stage 6 | 演奏表現への反映 | Performance Expression Mapping | 最終ベクトルをノートオンタイミング・アタック・リリース・演奏癖に反映する。 |
| Stage 6-B | 演奏癖パラメータ | Performance Trait Parameters | ビブラート・トレモロ・ポルタメントの癖を感情ベクトルと連動して演奏に付加する。 |

## 9. 感情アルゴリズム

感情間の変調関係のトポロジー定義。FM音源のアルゴリズム概念に相当する。

| 日本語 | English | 定義 |
|---|---|---|
| キャリア感情 | Carrier Emotion | Valence-Arousalベクトルへ直接寄与する感情。 |
| モジュレータ感情 | Modulator Emotion | キャリア感情の変換特性を変調する感情。 |
| 直列接続 | Series Connection | モジュレータ感情がキャリア感情を変調してから最終出力へ至るトポロジー。効果が増幅されやすく複雑な感情の質感が生まれる。 |
| 並列接続 | Parallel Connection | 複数の感情が独立してベクトルに寄与しベクトル加算されるトポロジー。相反する感情が並列接続されるとstrengthが低下する。 |
| フィードバック接続 | Feedback Connection | ある感情が自己変調するループ構造のトポロジー。感情が自己強化されやすく発狂状態への最短経路になり得る。 |
| 感情アルゴリズム | Emotion Algorithm | 9感情間の変調関係のトポロジー全体。演者ごとに定義される。 |
