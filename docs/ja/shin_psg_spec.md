# シン・PSG 仕様書 v0.3

## 概要

「シン・PSG」は日本の電子音楽の系譜を継承し、発展させた電子音楽の演奏方法を定義する概念である。  
音源の種類ではなく、演奏方法そのものを定義することを本質とする。

電子音楽の定義に則り、以下の音源を包含する：

- PSG（Programmable Sound Generator）
- FM音源
- PCM音源
- およびこれらに準ずる電子音源

演奏データはMML（Music Macro Language）またはピアノロールなど、  
一般的な電子音楽制作手法によって作成される。

---

## 命名の由来

### なぜ「シン・PSG」なのか

日本の電子音楽はPSG（Programmable Sound Generator）を基盤として発展してきた。  
MSX・Sharp X1・PC-88・ファミリーコンピュータ等のプラットフォームにおける音楽文化は  
PSGを出発点として独自の進化を遂げており、この概念の命名はその歴史的経緯に基づく。

「シン」には以下の複数の意味が重なっている：

- **新** ── 新しい定義・概念としての電子音楽
- **真** ── 日本の電子音楽の本質を継承するという意志
- **進** ── 時代に合わせて進化させた電子音楽
- **深** ── 演奏表現の深化

### 派生命名について

本仕様は「シン・PSG」を標準の名称とするが、  
以下の名称を用いることも一向に差し支えない。  
これらはすべて同一の仕様・概念を指す：

- **シン・BEEP** ── BEEPサウンドを起源として捉える場合（この指摘はごもっとも、である）
- **シン・FM** ── FM音源を中心として捉える場合
- **シン・PCM** ── PCM音源を中心として捉える場合

音源の種類によって命名を変えることは、本仕様の精神に沿った自然な選択である。

## チップチューンとの関係

「チップチューン（Chiptune）」は、西洋のデモシーン文化およびゲームミュージック文化を起源とする概念であり、  
それ自体として固有の歴史と文化的価値を持つ、素晴らしい音楽ジャンルである。

一方、日本の電子音楽は異なる起源と異なる進化の経緯を持つ。  
両者はともに電子チップ（IC）を用いた音源を使用しているが、  
「電子チップを使用している＝チップチューンである」という等式は成立しない。  
起源・文化的背景・発展の経緯が異なる以上、両者は区別されるべき独立した概念である。

シン・PSGは日本の電子音楽の系譜に立脚しており、  
チップチューンを否定するものではなく、明確に区別されるものとして定義される。

## データ構造

### 音符トラック（Note Track）

従来の電子音楽と同様に、各パートの音符データを時間軸上に記述したトラック。  
MMLまたはピアノロール形式で作成される。

### フィールトラック（Feel Track）

シン・PSGにおける新概念。  
楽曲の各パート（楽器パート）ごとに定義される感情パラメータのトラック。  
音符トラックと同様に時間軸上に配置され、各感情パラメータの値が  
自由な変化曲線（エンベロープカーブ）として記述される。

フィールトラックは作曲家が意図した感情表現であり、  
演奏時には指揮者および演者を通じて解釈・変質されるため、  
フィールトラックの値がそのまま演奏に反映されるわけではない。

指定可能な感情パラメータ（各パラメータは数値で指定）：

| パラメータ名 | 英語名 |
|---|---|
| 希望 | Hope |
| 怒り | Anger |
| 悲しみ | Sadness |
| 喜び | Joy |
| 楽しみ | Fun |
| 嫉妬 | Envy |
| 貪欲 | Greed |
| 虚無 | Void |
| 不安 | Anxiety |

## 演奏エンジン構造

### 指揮者（Conductor）

演奏時においてフィールトラックを解釈し、各演者へ伝達する役割を担う。

指揮者のパラメータ：

| パラメータ | 説明 |
|---|---|
| 解釈傾向（Interpretation） | フィールトラックの感情をどのように解釈するかの傾向。誇張する方向か抑制する方向かを規定する。 |
| カリスマ（Charisma） | 演者へのフィール伝達の強度。高いほど演者への影響が強く、低いほど演者は自身のパラメータに従う。 |
| 伝達遅延（Latency） | フィールトラックの変化が演者に伝わるまでの時間的遅れ。 |

指揮者単体（演者が未定義）の場合、指揮者のみが存在しても演奏表現への影響は発生しない。  
演者が存在して初めて指揮者の機能が有効となる。

---

### 演者（Performer）

各音符トラックを演奏する主体。FM音源のオペレータ定義と同様の概念で、  
トラックごとに演者を割り当てて定義する。

演者は指揮者またはリーダー演者経由でフィールトラックの感情パラメータをリアルタイムに受け取り、  
自身の内部感情パラメータが時々刻々と変動する。  
この変動は指揮者および演者自身のフィルタを通過するため、  
フィールトラックの値と一致するとは限らず、場合によっては過剰反応が生じる。

#### 感情感度パラメータ

各フィールに対応した受け取りやすさを規定するパラメータ群。

| パラメータ | 説明 |
|---|---|
| 楽観度（Optimism） | 希望・喜び・楽しみへの感度 |
| 忍耐度（Patience） | 怒り・不安への耐性。低いほど過剰反応しやすい。 |
| 真面目度（Seriousness） | 悲しみ・虚無・嫉妬への感度 |

#### 感情動特性パラメータ

感情の受け取り方・変動の仕方を規定するパラメータ群。

| パラメータ | 説明 |
|---|---|
| 感度（Sensitivity） | 感情変化へどれだけ速く・強く反応するか |
| リミッター（Limiter） | 感情パラメータの上限・下限の振れ幅 |
| 感情減衰速度（Decay） | 受け取った感情が収束するまでの速さ |
| 追従性（Tracking） | フィールトラックの急激な変化カーブにどれだけ追従できるか |

#### 技術パラメータ

| パラメータ | 説明 |
|---|---|
| 熟練度（Skill） | 演奏精度全般。低いほど感情の影響が演奏に直接的・素直に表れる。高いほど感情が高ぶっても減衰速度が速く、演奏精度を維持しやすい。 |

#### 指揮者・リーダーに関するパラメータ

演者自身が指揮者代替（リーダー）として機能する場合、または指揮者不在時に独自解釈を行う場合に使用するパラメータ群。  
すべての演者がこのパラメータを保有する。

| パラメータ | 説明 |
|---|---|
| 解釈傾向（Interpretation） | 指揮者不在時、またはフィールトラックを独自解釈する際の感情解釈の傾向 |
| カリスマ（Charisma） | リーダー演者として他の演者へ影響を与える際の伝達強度 |
| 伝達遅延（Latency） | リーダー演者からの影響が他の演者に伝わるまでの時間的遅れ |
| 信頼感（Trust） | リーダー演者に対する信頼の度合い。高いほどリーダーの感情状態を素直に受け取り、低いほど独自解釈の傾向が強まる。 |

## 演奏モード

演奏時の動作は、指揮者・リーダー演者・演者の定義状況によって以下のように変化する。

### モード1：通常演奏（指揮者・演者ともに未定義）

フィールトラックは無効。決定論的な通常の楽曲演奏が行われる。

### モード2：演者のみ定義（指揮者なし・リーダーなし）

指揮者が存在しないため、各演者はフィールトラックを独自に解釈する。  
演者自身の解釈傾向パラメータに従い、フィールトラックを直接参照して  
各自の内部感情パラメータへ反映する。  
演者間の感情状態は互いに独立しており、統一された解釈は行われない。

### モード3：指揮者あり・演者あり（標準構成）

指揮者がフィールトラックを解釈し、カリスマ・解釈傾向・伝達遅延を通じて  
各演者の内部感情パラメータへ影響を与える。  
演者は自身のパラメータでさらにフィルタリングして演奏表現へ反映する。

### モード4：指揮者あり・演者なし

指揮者のみが存在しても演奏表現への影響は発生しない。  
実質的にモード1（通常演奏）と同等となる。

### モード5：リーダー演者あり（指揮者なし・バンド構成）

特定の演者を「リーダー（Leader）」として指定することで、  
指揮者の代替として機能させることができる。  
バンドにおけるパーカッション（ドラム）等、  
テンポ・グルーヴの中心となるパートをリーダーに指定することを想定している。

**リーダー演者の動作：**

- リーダー自身もフィールトラックを独自解釈して演奏する（演者としての機能）
- 同時に自身の解釈傾向・カリスマ・伝達遅延パラメータを用いて他の演者へ感情状態を伝達する（指揮者代替としての機能）

**リーダー以外の演者の動作：**

- リーダーからの伝達を、自身の信頼感（Trust）パラメータで受け取る
- 信頼感が高いほどリーダーの感情状態に従い、低いほど自身の独自解釈が優先される
- 信頼感が低い演者が複数存在する場合、アンサンブルとしての統一感が失われ、演奏が個性的または混乱した状態になる可能性がある

---

## 演奏時の動作フロー（モード3：標準構成）

```
フィールトラック（作曲家の意図する感情カーブ、時間軸上に記述）
    ↓
指揮者による解釈・変換
（解釈傾向・カリスマ・伝達遅延を通じてフィルタリング）
    ↓
各演者の内部感情パラメータへリアルタイム反映
（演者の感度・楽観度・忍耐度・真面目度・リミッター・減衰速度・追従性でさらにフィルタリング）
    ↓
演奏表現への影響
  ├── ノートオンのタイミング変動
  ├── アタック（音の立ち上がり強度）の変化
  └── リリース（音の余韻・収束）の変化
    ↓
音源出力（PSG / FM / PCM）
```

## 発狂状態（Breakdown State）

演者の内部感情パラメータがリミッターを超過した場合、「発狂状態（Breakdown）」へ移行する。

**発狂状態における演奏への影響：**

- ノートオンタイミングの偏差が制御不能なほど拡大する
- アタック強度が不規則に極端な値を取る（過剰または消失）
- 最悪の場合、本来のトラックとは無関係なノートが発音される（暴走）
- あるいは演奏が完全に停止する（フリーズ型崩壊）

**発狂状態からの回復：**

- 指揮者がカリスマを行使して介入することで演者を収束させられる
- リーダー演者が安定している場合、リーダーへの信頼感が高い演者はリーダーの安定状態の伝播によって回復しやすい
- 他の演者の安定した演奏状態が伝播することで引き戻される効果がある（アンサンブルの相互影響）
- 指揮者・リーダーの能力が低い場合、または信頼感が低い演者が多い場合、発狂状態の収拾がつかないまま演奏が崩壊する可能性がある

---

## シン・PSGの特性

- 指揮者または演者が定義されている場合、同一の楽曲データであっても毎回異なる演奏結果が生成される（非決定論的演奏）
- 指揮者・リーダー演者・演者の定義の組み合わせによって演奏の個性・解釈・アンサンブルの統一感が変化する
- 指揮者および演者がともに未定義の場合は、通常の決定論的楽曲演奏となる（フィールトラックは無効化される）
